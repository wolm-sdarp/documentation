> Это документация по работе с GitHub'ом проекта WoLM SDARP.
> Документацию по самой платформе GitHub от разработчиков можно найти [тут](https://docs.github.com/ru).
## GitHub Organization
Работа над проектом ведётся в [организации WoLM SDARP](https://github.com/wolm-sdarp). Там же публикуются результаты (продукты) проекта — книги, формы контроля, дополнительные материалы.

## GitHub Projects
В организации существует проектный менеджмент через [GitHub Projects](https://github.com/orgs/wolm-sdarp/projects).



### Issue Types
| Тип             | Описание                              |
| --------------- | ------------------------------------- |
| Task            | Content development task              |
| Bug             | An unexpected problem or behavior     |
| Feature         | A request, idea, or new functionality |
| Mistake         | Incorrect thing in content            |
| Learning Design | Learning design task                  |

### Issue fields
> Issue fields одинаковы для всех репозиториев и настраиваются через `Organization Settings > Planning > Issue fields`

| Поле        | Описание                                           | Значение                                              |
| ----------- | -------------------------------------------------- | ----------------------------------------------------- |
| Priority    | Current importance level assigned to this issue    | `Critical` \| `High` \| `Medium` \| `Low` \| `Lowest` |
| Effort      | Relative level of effort for completing this issue | `High` \| `Medium` \| `Low`                           |
| Start date  | Date when work on issue will begin                 | Дата                                                  |
| Target date | Expected completion date for this issue            | Дата                                                  |
